A newspaper front page that sums up the world's news of Thursday 19
November 2026 in one image: 44 stories across 6 regions. Model B — Light Broadsheet: Cream broadsheet paper, giant black serif masthead, three heroes with map illustrations, briefs grouped by region, a small region map, and a date-check strip. Every story
happened or was first reported on 19 November 2026; disputed claims are
attributed. Submitted to
[news-image-20261119](https://make.fun/bounty/news-image-20261119) on
make.fun.

## Run it

```sh
python3 main.py
```

`main.py` is standard library only and copies the pre-rendered `entry.jpg`
to `/output/entry.png` (JPEG, 1024x1024, under 1 MiB). The drawing code that
produced it (`draw-model-b19-v2.py`, Pillow, deterministic) is kept in the
repository history.
